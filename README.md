# DevAssist AI

## Descrição

O DevAssist AI é um sistema especialista desenvolvido em Python e Flask para auxiliar estudantes e desenvolvedores iniciantes no aprendizado de programação.

A aplicação permite:

* Consultar conceitos de desenvolvimento de software;
* Explicar estruturas básicas de código;
* Gerar modelos de README;
* Apoiar o aprendizado de tecnologias como Git, GitHub, Python, Flask e APIs.

## Tecnologias Utilizadas

* Python
* Flask
* HTML
* CSS
* JavaScript

## Funcionalidades

### Mentor Dev

Consulta conceitos de programação através de uma base de conhecimento local.

### Explicador de Código

Identifica estruturas básicas da linguagem Python e apresenta explicações.

### Gerador de README

Cria automaticamente um modelo de documentação para projetos.

## Como Executar

1. Instale o Python.
2. Instale o Flask:

```bash
pip install flask
```

3. Execute:

```bash
python app.py
```

4. Abra o navegador:

```text
http://127.0.0.1:5000
```
